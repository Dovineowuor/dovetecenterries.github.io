# Contributing to Dovetec Enterprises

First off, thank you for considering contributing to Dovetec Enterprises! It's people like you that make bridging the workforce complexity gap possible.

## Where do I go from here?

If you've noticed a bug or have a feature request, make sure to check the [Issues](../../issues) to see if someone else has already created a ticket. If not, go ahead and [make one](../../issues/new)!

## Setup

1. **Fork** the repository on GitHub.
2. **Clone** your fork locally:
   ```bash
   git clone https://github.com/YOUR_USERNAME/doveteced.github.io.git
   ```
3. **Branch out**. Create a descriptive branch name:
   ```bash
   git checkout -b feature/your-awesome-feature
   ```
   Or for bugs:
   ```bash
   git checkout -b fix/issue-123
   ```
4. **Environment Setup**: Follow the setup instructions in the [README.md](README.md) to initialize the virtual environment and database.

## Making Changes

- Ensure your code adheres to standard PEP-8 style guidelines for Python.
- If you're working on frontend templates, try to reuse existing Bootstrap/CSS paradigms found in the project.
- Write docstrings for new methods and inline comments where logic might be obscure.

## Committing

Write clear, concise commit messages.

- Use the present tense ("Add feature" not "Added feature").
- Use the imperative mood ("Move cursor to..." not "Moves cursor to...").
- Limit the first line to 72 characters or less.

## Submitting a Pull Request

1. Push your branch to your fork:
   ```bash
   git push origin feature/your-awesome-feature
   ```
2. Open a Pull Request from your repository to our `main` branch.
3. Keep an eye out for any comments from reviewers!

Thanks to all our contributors!
